# Group 21 – Tech Gadget Store

## 1. Project Overview

Tech Gadget Store is a web-based gadget shopping platform designed to display technology products, their specifications, and provide customers with an interface for placing orders.

The project is developed using three core frontend technologies:

- **HTML:** Provides the structure and content of the website.
- **CSS:** Handles the appearance, layout, and responsiveness.
- **JavaScript:** Adds interactivity and dynamic functionality.

## 2. Project Structure

```text
My_Gadget_store/
│
├── index.html
├── products.html
│
└── images/
```

### File and Folder Description

| File/Folder | Description |
|---|---|
| `index.html` | The homepage. Introduces the store and displays product categories. |
| `products.html` | Displays available gadgets, prices, and product specifications. |
| `images/` | Stores product images used throughout the website. |

## 4. Planned Website Features

### Product Management
- Display available gadgets.
- Show product descriptions and specifications.
- Search for products.

### Product Comparison
- Select two gadgets.
- Compare their specifications side by side.

### Shopping Cart
- Add products to the cart.
- Track the number of items.
- Calculate the total price.
- Remove products from the cart.

### Order Management
- Collect customer information.
- Display an order summary.
- Provide an order placement interface.

## 6. Development Approach

The project will be developed in phases:

1. HTML – Build the website structure.
2. CSS – Style the website and make it responsive.
3. JavaScript – Implement interactive features.
4. Integration – Connect the pages and test functionality.

## 7. Project Status

**Current stage:** HTML development.

Additional pages and functionality will be implemented progressively.
